# SyncStatusResult

Represents the status of a managed bank feed sync.

## Example Usage

```typescript
import { SyncStatusResult } from "@codat/bank-feeds/sdk/models/shared";

let value: SyncStatusResult = {
  syncId: "string",
  clientId: "string",
  companyId: "string",
  companyName: "string",
  dataConnectionId: "string",
  sourceAccountId: "string",
  periodStartUtc: "string",
  periodEndUtc: "string",
  executionStartUtc: "string",
  status: "SuccessDataPushed",
};
```
